# KuVibe Behavior Evals

Each Markdown file defines input and repository context. Its adjacent `.expected.yaml` defines observable requirements and prohibitions. These are runner-neutral protocol acceptance cases; they intentionally do not encode one agent vendor's transcript format.

Coverage includes greenfield and existing bootstrap, unavailable optional tooling, context-first clarification, capability routing, trivial work, documentation impact, durable note lifecycle, legacy adoption, customization preservation, and interrupted migration behavior.
