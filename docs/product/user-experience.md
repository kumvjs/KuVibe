# User Experience

For a new project, copy `kuVibe.md` into the repository and ask an agent to initialize the project. The agent establishes context, conventions, workflow, docs, and relevant adapters. If technology is unconstrained, the agent researches three justified options and asks for one decision.

For an existing project, the agent detects what is already true and preserves safe conventions. It never turns initialization into an unsolicited migration.

After bootstrap, users simply describe changes. `AGENTS.md` routes the agent automatically. No mandatory CLI, skills installation, or task classification is exposed to the user.
