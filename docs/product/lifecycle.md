# Lifecycle

```text
Intent -> version check / safe upgrade -> context retrieval -> completeness -> clarification if material
       -> scope/risk/complexity -> relevant perspectives -> acceptance
       -> plan -> implementation -> verification/review
       -> living docs -> engineering note
```

Project context holds durable facts. Documentation holds current behavior. Timestamped notes hold why the system changed. Together they let the next agent work from evidence instead of rediscovering the project.
