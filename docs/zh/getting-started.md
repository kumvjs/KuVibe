# 快速开始

KuVibe 不需要安装，也不要求你学习新的 CLI 或工作流命令。准备一个项目目录和支持读取项目文件的编码智能体即可开始。

## 1. 复制 `kuVibe.md`

下载 [kuVibe.md](https://raw.githubusercontent.com/kumvjs/KuVibe/main/kuVibe.md)，并将它放在新项目或现有项目的根目录中。

```text
your-project/
└── kuVibe.md
```

## 2. 让智能体初始化项目

在项目中打开编码智能体，然后发送：

```text
阅读 @kuVibe.md 并初始化这个项目。
```

智能体会先检查仓库现状。全新项目会建立必要的项目上下文和工作流；现有项目会识别并保留已有技术栈与约定。只有影响结果的重要信息缺失时，它才会请你做选择。

## 3. 直接描述你的需求

初始化完成后，像平常一样描述你想实现的结果：

```text
给设置页增加深色模式，并记住用户的选择。
```

生成的 `AGENTS.md` 会引导后续工作自动使用项目上下文、验收标准、验证和工程记忆。你只需继续描述需求。

::: tip 如何确认初始化完成？
项目根目录中应当出现 `AGENTS.md`、`.agents/project.md` 和 `.agents/context/stack.md`。它们记录了后续工作需要的长期上下文。
:::
