# `kuVibe.md`

The primary artifact is a bootstrap specification, not a technology handbook. It defines how to discover context, resolve requirements, route complexity, collaborate through artifacts, implement, verify, document, remember decisions, and degrade gracefully.

It deliberately does not prescribe framework techniques. Project-specific rules are generated into context from repository evidence and current authoritative guidance.

Its header also declares protocol SemVer, the current Project Schema, and the minimum supported schema. To preserve the copy-one-file experience, it carries a compact supported migration index while `migrations/` stores the expanded maintainer specifications.
