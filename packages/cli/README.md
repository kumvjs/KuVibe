# `@kuvibe/cli`

Optional, read-only, deterministic helpers for coding agents using KuVibe.

```bash
npx -y @kuvibe/cli detect [root]
npx -y @kuvibe/cli validate [root]
npx -y @kuvibe/cli docs-nav [docs-root]
```

All commands print JSON. `validate` includes KuVibe release/schema state consistency and applied template revisions. This package is never required to use `kuVibe.md`.
