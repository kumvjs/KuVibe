# Development Workflow

- Level 0: analyze, implement, verify.
- Level 1: analyze, plan, implement, verify, assess docs, write a note if meaningful.
- Level 2: synthesize relevant professional perspectives, define acceptance, plan, implement, review, verify, update docs, write a note.
- Level 3: research and architecture synthesis, obtain human approval, then plan, implement, review, verify, update docs, and write a note.

Implement the smallest coherent change. Preserve established conventions, keep deterministic tools side-effect free, and update tests with behavior.
